# 版本更新与升级核对

源码开发版可从侧栏底部的版本号进入“关于”，从更多菜单或新版本提示进入“版本更新”。已发布的 0.2.0-preview.2 尚不含此入口；源码提交、日常 CI 和新的安装版分别判断。

侧栏常驻实际构建版本与 GitHub 仓库入口；更多菜单提供检查更新、更新日志、反馈问题、在线文档与关于。默认在首屏显示 15 秒后查询公开版本，前台最多每 6 小时再查；设置中可关闭自动检查。只检查不会下载、安装、退出或修改分流，后台失败不弹窗。普通侧栏与窄屏导航共享同一份查询结果，不分别请求。

## 用户流程

1. 选择“仅稳定版”或“包含预览版”，点击“检查更新”。通道只影响版本检查，不影响分流；偏好保存在本机桌面配置中。
2. 查看版本、发布时间、对应系统架构的安装文件、发布说明和 SHA-256。说明按纯文本显示，不运行其中的 HTML。
3. 点击“备份并下载”：先保存升级前备份，再在应用内下载，显示进度，可取消、重试。下载完成后核对文件长度和 SHA-256；失败不进入可安装状态。
4. Windows 用户级安装版显示“安装并重启”：再次读取发布元数据、校验本机文件并保存新备份，等待自己的后台退出后运行固定 NSIS 安装器，退出旧应用并自动重新打开。目录运行版只打开下载目录；Mac 打开已校验的 DMG，由用户退出后拖入应用程序文件夹替换。尚无签名/公证，不绕过系统安全检查。
5. 新版启动后只读核对旧应用设置、收藏、语言、代理策略；在更新入口查看结果。设置保留、规则加载和真实新连接验证是三个不同结果。

核对发现差异时只提示，不覆盖用户新选择、不重放备份。新增扫描应用不算丢失旧设置。核对依赖升级前备份；备份被删除、修改或管理记录待核对时不能显示成功。手动及升级前备份由用户清理。

## 检查与信任边界

- 只读取 `Yueyuyu/app-route` 的公开 Release，不读取登录 Token，也不上传应用清单或代理配置。
- 版本按项目的数字版本/`preview.N` 顺序比较；稳定通道排除预览版，两者都排除草稿和未知标签，不建议回退到更旧版本。
- 只接受当前平台架构的 EXE/DMG、固定仓库下载地址、已上传状态及 SHA-256 摘要。源码压缩包不作为安装包。附件缺失或接口失败不能显示“已是最新”。
- 单次请求限时 10 秒、响应上限 2 MB；进行中的查询合并，成功结果缓存 60 秒，限流后 15 分钟再试。时间表示实际读取时刻，缓存不会伪装成新检查。
- 开始下载要求检查结果在 15 分钟内；安装前重新读取元数据（仍尊重限流），发布摘要变化则拒绝安装。只允许固定仓库的 HTTPS 资产及 GitHub 资产 CDN 重定向，不传账户凭据。安装包限制 512 MiB、下载限时 10 分钟，写入独立临时目录，完成后原子改名；校验失败或取消移除未完成文件。
- 下载摘要来自 GitHub 元数据，不等于独立发布者签名或公证。渲染进程只能传通道与版本，不能指定可执行路径、下载地址或命令参数；安装前再次校验文件路径、大小和哈希。
- 有未完成分流事务、管理记录异常、设置操作进行中或备份失败时不安装。安装期间拒绝新的写入；安装器未启动则保持当前应用可用，不把“已启动安装器”当作安装成功。普通关闭或退出不会偷偷安装。
- macOS 双架构构建不等于 Mac 真机分流验收。当前日常检查和隔离桌面数据也不能替代真实网络验收。

实现分为 `core/releaseUpdates.ts`（版本/资产约束）、`main/desktop/releaseUpdates.ts`（固定源查询与限频）、`main/desktop/updateInstaller.ts`（下载与校验）、`main/desktop/windowsUpdate.ts`（NSIS 安装身份和固定参数）、`main/services/upgradeVerification.ts`（备份/核对）和 `renderer/components/UpdatePanel.tsx`（交互）。升级功能不改用户代理规则。

验证：`tests/releaseUpdates.test.ts`、`updateInstaller.test.ts`、`windowsUpdate.test.ts` 覆盖版本、地址、架构、摘要、取消、限流、备份失败、文件替换、重复安装和手动安装边界。`verify-settings-ui.mjs` 使用真实 Electron/IPC/文件存储与虚构安装字节，四语检查下载、备份、手动交接和侧栏状态。`verify-auto-update.mjs` 只由 Windows CI 干净安装验收调用，以合成旧版本标识/发布响应配合真实 NSIS 和安装版验证退出、重装、自启、产物一致及数据保留；结果见 `output/auto-update-check.json`。这不代替所有历史版本的数据迁移、真实 GitHub 下载链路或 Mac 实机升级验收。

参考 [Electron net](https://www.electronjs.org/docs/latest/api/net) 和 [GitHub Release API](https://docs.github.com/en/rest/releases/releases)。
