# 产品完善实施清单

来源：2026-11-16 产品、桌面流程与相关代码审查；用户授权全部逐步实施。每批独立验证、提交和推送，未完成项不写成已交付。

## 批次

- [x] 1. 状态刷新合并/退避、隐藏降频、按应用公平采样及完整状态统计；隔离回归与反向验证，不代表实机性能提升百分比。
- [x] 2. 应用详情聚合、连接路径与时间、针对应用的只读诊断；四语隔离交互验证，不以演示连接替代实机。
- [x] 3. 更新检查、发布通道、版本摘要、可信下载入口与升级备份核对；实现与边界见 [更新流程](UPDATES.md)，安装仍由用户手动执行，签名/公证与正式发布单独验收。
- [x] 4. 紧凑导航/筛选、七天最近发现、图标管理统一统计与待完善入口、任务式帮助；只导航或筛选，不自动修改分流。
- [x] 5. 导入差异汇总、未匹配人工绑定、备份信息与字段差异；绑定只重建预览，重新勾选才导入，保留冲突与失败恢复检查。
- [x] 6. 规则与操作记录、修改来源、带并发检查的单步撤销；[撤销范围](ROUTING-HISTORY.md)限定联网选择，策略变化和旧身份需通过预览核对。
- [x] 7. 后台持久化临时分流、到期恢复与冲突保护，托盘快捷操作；[期限语义与恢复边界](TEMPORARY-ROUTING.md)，未通过恢复检查时明确待恢复，重启电脑后需打开应用续接。
- [ ] 8. 用户自建场景方案及应用前差异预览、路径变化提示与确认重绑。
- [ ] 9. 按应用域名例外，严格匹配优先级、所有权及恢复；更多 Mihomo 客户端能力契约与适配。
- [ ] 10. 四语、桌面实际交互、隔离故障、覆盖升级及分层发布验收。

## 持续边界

保留用户原配置与规则；不自动开启 TUN、改系统代理或重启其他软件。已安装预览版与开发源码分别标记。签名/公证依赖发布者证书；Mac 实机依赖可用设备；成功订阅刷新依赖上游正常响应。无法在当前环境完成的外部验收保持待办，不用 CI 或模拟结果冒充。

实施入口见 [模块索引](engineering/subsystems.md)，原验收缺口见 [验证记录](VERIFICATION.md)。
