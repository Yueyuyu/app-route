# 设置导入与备份

本功能已进入源码开发版本；已发布的 `0.2.0-preview.2` 安装包不包含本轮新增界面。没有重新发布二进制前，不改下载清单。

## 使用流程

同页的 [场景方案](SCENARIOS.md)可以保存一组应用的联网选择，使用时进入这里的差异预览；不恢复全局代理策略或显示语言。

在“设置与备份”导出 JSON，或选择已有文件进入预览。当前格式为 `app=AppRoute`、`kind=approute-settings`、`version=1`；兼容旧 `application-routing-snapshot` 导出。文件最大 2 MB，最多 5000 条资料，每次选择最多 100 个应用。

预览按本机可读取的程序完整路径匹配；不按名称猜测。已有专属分流默认不勾选，未匹配或共享系统进程不可选择。可展开条目核对名称、分类、收藏和联网方式的具体差异；汇总按可导入、未匹配、有变化分别计数。勾选已有条目意味着明确替换该条目的资料及所选联网方式。

旧电脑路径不一致时，可点击“绑定本机应用”，从本机确认的候选中选择正确程序。源路径与目标路径分别显示，不接受任意路径或重复目标；共享系统进程不在候选中。确认绑定只重建预览，所有勾选清空，须重新选择再导入。资料变更、预览过期或程序移除时停止，不使用旧预览覆盖新设置。

- **仅导入资料**：合并名称、分类和收藏，不应用联网方式。
- **导入并应用**：确认后将所选应用交给原有分流事务；未选应用的规则保持原样。代理应用默认跟随当前绑定组。
- **恢复文件中的代理策略**：默认关闭；打开后还会统一迁移当前代理应用的跟随组。不会更改用户原有代理组的成员或手选节点。
- **恢复显示语言**：默认关闭，独立选择；导入期间的新语言选择不会被旧预览覆盖。

文件保存本机程序路径及代理组/节点名称，请妥善保管，不作为公开诊断附件。它不含订阅、凭据、完整内核配置、自定义图标、辅助进程缓存和连接验证记录。旧的仅进程名规则不自动迁移到另一台电脑；未匹配项目可人工绑定，候选缺失时先扫描或添加正确路径，再重新预览。

## 保留与失败处理

### 程序路径变化

“检查程序路径”只读核对已管理应用的主程序文件是否可用。发现失效路径时进入预览，从扫描确认的候选中手动绑定，再重新勾选；差异表展示旧路径 → 新路径，确认窗口说明旧路径规则将被替换。它不是实时安装监听，旧版只有进程名的记录不猜测路径。

只有原路径已失效且目标未被另一应用管理时才允许替换。临时分流须先结束；原路径重新出现、新路径不可用或设置已变化则停止。确认应用时沿用原管理编号，以同一恢复事务替换该应用的旧路径规则，重新识别辅助进程，保留其他应用与用户原规则。代理应用按预览中明确显示的当前绑定组处理。

“仅导入资料”不删除旧分流身份；只有分流事务成功后才迁移对应资料和收藏。失败恢复旧规则，资料保存失败单独报告并保留备份。重绑不修改程序文件、快捷方式或文件关联。

每次导入先保存 `backups/settings` 下的白名单设置快照；不能安全备份时停止导入。设置导入不会直接覆盖 `state.json`、Clash 配置或其他覆写文件。

分流应用复用 `RoutingService.applyAutomatically` 的校验、冲突检查、守护与失败回退；辅助路径由后台重新识别。预览十分钟有效，设置发生变化则需重新预览。资料写入带修订校验，导入后重新加载，防止旧页面缓存覆盖新设置。

网络和多个本地文件不是一个数据库事务。网络应用失败时不保存导入资料；网络成功但后续资料/语言保存失败时，界面明确报告未完成部分并保留导入前备份，不声称整体成功或擅自撤销期间的新选择。

## 可视化备份管理

“本机备份”按时间列出来源、应用数量、文件大小与可恢复状态，支持立即备份、预览恢复、导出和单份确认删除。恢复与导入共用字段差异、人工绑定及语言/策略对照。删除前重新核对内容指纹，仅删除所选快照，不碰当前规则、事务原件或离线恢复工具；损坏与待确认记录不能直接恢复、导出或删除。

`backups/settings` 的手动和导入前备份包含资料、收藏、语言与策略，由用户清理；`backups/state` 沿用最近 20 份历史记录的现有保留机制。分流历史导出带 `scope=routing`，不携带收藏与语言；恢复时保留当前名称、分类和收藏。旧导出没有收藏字段时也保留当前收藏，不把“缺失”当成“取消”。

恢复与设置导入共用预览和安全事务，已有分流仍默认不勾选。不同电脑路径不一致时不会猜测匹配。备份管理用于选择性恢复 AppRoute 设置，不是系统还原，也不能代替断网时的独立恢复入口。

## 实现入口与验证

| 位置 | 职责 |
| --- | --- |
| `src/core/settingsTransfer.ts` | 输入格式、大小、路径与策略校验 |
| `src/shared/settings.ts` | 导出、预览、导入和备份协议 |
| `src/main/services/settingsTransfer.ts` | 本机匹配、预览指纹、合并及安全事务 |
| `src/main/services/settingsBackups.ts` | 备份的限定路径、白名单读取及变更核对 |
| `src/renderer/components/SettingsPage.tsx` | 文件操作、差异预览、勾选与确认 |
| `src/renderer/components/SettingsBackupsPanel.tsx` | 备份列表、创建、恢复预览、导出及删除确认 |
| `scripts/verify-settings-ui.mjs` | 隔离 Electron、原生文件入口、四语窄窗口及 IPC 验收 |

`npm run check` 包含格式、旧格式兼容、冲突、旧缓存、原规则保留和失败回退回归；`npm run check:settings-ui` 使用真实桌面与设置存储、模拟路由后台，不接触用户配置。该检查纳入日常 UI CI 与发布前验收，不能代替 Mac 真机分流验证。

域名例外的导出、差异预览、历史备份与旧格式兼容见 [按应用域名例外](DOMAIN-EXCEPTIONS.md)。缺少例外字段的老文件不清除当前例外。
