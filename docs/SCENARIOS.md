# 场景方案

源码开发版本在“设置与备份”提供场景方案。新建时填写名称，勾选 1 至 100 个应用并选择联网方式；最多保留 20 个方案。保存、查看和删除方案都不会改变网络。

使用“预览应用”进入设置导入的差异预览，重新确认勾选应用后才应用。未选择的应用保持原样，代理应用跟随当前绑定组；方案不保存订阅、节点、全局策略、语言、收藏或临时期限。临时设置中的应用须先结束期限，受保护程序不可保存到方案。

方案只保存在本机数据目录 `scenarios`，文件包含程序路径，不应公开分享。删除只移除所选方案，不撤销已应用规则。名称相同、来源已变化、文件损坏、未知版本或指纹不一致时拒绝覆盖；无法读取的原件保持原样。

网络应用共用 `SettingsTransferService` 和标准恢复事务：先核对本机程序身份和差异，再备份、检查、写入、验证；失败保留原设置。换电脑或程序路径变化必须重新匹配，不能仅按应用名称猜测。已发布安装包不会因源码推送自动获得该功能。

实现入口：`SettingsScenarios` 负责固定目录存储和草稿核对；`SettingsScenariosPanel` 负责编辑、预览和删除确认。回归覆盖只读操作、旧草稿、无效项目、文件变化、临时状态及真实事务失败回退；四语隔离桌面检查覆盖保存、预览、取消及删除，不冒充日常网络或 Mac 实机验收。
