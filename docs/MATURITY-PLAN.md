## 实机验收边界

- preview.2 的 Windows 101 项自动测试通过（另有 2 项仅在 Mac 原生运行），两种 Mac 架构各 103 项通过；包含隔离模拟的超时/离线恢复、确认状态保存间隙、外部冲突、失效组、记录修复、备份上限、脱敏导出、自检过期、空连接响应及自动组重载保护。
- 55 项四语桌面检查通过，使用真实 Electron 壳和隔离演示后台；包括关于链接/复制、共享自检时间和断线/切点/合成唤醒事件，不属于实际网络写入或整机睡眠证据。
- 本机 Mihomo `-t` 已通过组消失时 REJECT 配置的离线验证。
- 用户此前完成正常托盘重启。本轮另完成两份真实订阅往返切换：当前 29 个应用的管理记录未变，返回后 179 条专属规则与原有规则顺序、各组选择及运行配置一致，观察到最新规则重新生成，自检 5/5。另一份订阅缺少绑定组时明确处于组缺失状态，沿用原有规则符合既有策略，不重写应用目标；不将这项结果扩大为远程订阅刷新或所有客户端兼容。
- 2026-11-12 补完最终 Windows 安装版的真实桌面展示、关于键盘关闭/重开及带时间的 5/5 自检。当前远程订阅刷新被服务器以 HTTP 403 拒绝，失败后管理记录、原有规则与组选择保留；成功刷新后的再生成仍待验证。
- 同日完成设置已确认时的真实睡眠唤醒核对，规则及选择保留，自检 5/5；未确认事务跨睡眠仍待验证。随后桌面验收期间的异常请求另行记录，并隔离复现、修复自动组旧固定缓存被重载读回的问题，见最新验证记录。
- 独立真实内核及守护进程通过 5 类故障验收。发现并修复内核启动后空连接响应为 null 导致误报离线的问题。独立实例没有改动日常配置；未确认事务跨睡眠、断电及完整权限/守护异常矩阵仍未完成。
- 安装器为未签名预览版；本机 AVG 曾对新文件启动自动分析，未绕过或修改安全设置。构建成功或安装器退出码不能证明无恶意软件，需保留具体检测结果的边界。

## 本轮五项改进

自检时间、规则就绪文案、紧凑顶部和关于入口已经实现并通过隔离桌面检查。真实订阅切换、稳定状态下睡眠唤醒与独立进程故障验收已完成；Windows 新版安装与升级已核对 8 个既有数据文件及 5 个产物文件，未确认事务跨睡眠仍待完成。详细证据见 [验证记录](VERIFICATION.md)。

在已安装 Clash Party 的 Windows 开发机运行 `npm run check:recovery-faults`，可复验独立内核故障场景。脚本使用独立命名管道、回环端口及 `.runtime/recovery-faults`，仅运行虚构规则，检查日常配置哈希并清理自己启动的进程；不会切换日常订阅或设置系统代理。
