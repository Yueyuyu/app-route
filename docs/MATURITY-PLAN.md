# 六项成熟度改进

对应 2026-11-11 用户确认的六点建议。本轮按以下验收标准实现，结果以验证记录为准，不把隔离测试当作真实重启、休眠或订阅验收。

| 项目 | 实现与验收范围 | 进度 |
| --- | --- | --- |
| 可靠性 | 启动/唤醒后检查中断事务，保留恢复保护；补充崩溃点、超时、重生成与离线测试；记录真实客户端验收 | 代码与隔离测试通过；本机正常重启已观察到既有规则重新生成 |
| 代理失效 | 区分节点故障与代理组消失；明确可选的停止连接/沿用原规则行为，旧设置不静默改策略 | 已实现，故障分支测试通过 |
| 应用分类 | 已设置、正在运行、全部应用；收藏独立筛选；新发现标记不改变联网方式 | 已实现，四语桌面筛选验证通过 |
| 状态与详情 | 等待应用联网提示；连接概况/应用规则/恢复诊断分层；首次引导与缺失记录核对 | 已实现，四语桌面验证通过 |
| 性能定位 | 扫描、识别、校验、写入、重载与网络检查耗时；保持即时反馈和串行安全事务 | 已实现阶段计时，保留安全检查 |
| 安装与保护 | 可重复生成的用户级安装器、升级保留数据、版本迁移、受限备份、脱敏导出和管理记录修复 | 安装器已构建；升级数据与产物核验通过，当前目录安装及随后覆盖升级均通过 |

品牌资产保持定稿。默认沿用已有规则，保留修复通道；不把恢复网络扩展为重置系统代理或网卡。需要整机休眠、重启及生产订阅变更的验收单独列出，避免开发过程中打断当前工作。

## 实机验收边界

- 当前 88 项自动测试通过，包含隔离模拟的超时/离线恢复、确认状态保存间隙、外部冲突、失效组、记录修复、备份上限与脱敏导出。
- 46 项四语桌面检查通过，使用真实 Electron 壳和隔离演示后台，不属于网络写入证据。
- 本机 Mihomo `-t` 已通过组消失时 REJECT 配置的离线验证。
- 用户完成正常托盘重启，进程与生成文件时间对应本轮重启；生成规则与重启前管理记录一致，原有规则保留。重启后另有两笔已确认分流事务，最新规则顺序尚未经过下一次客户端重新生成；不能把旧版重启证据当作最新版本的持久化观测。整机休眠按用户要求稍后执行；订阅切换、断电、守护被结束及完整兼容矩阵仍未完成。
- 安装器为未签名预览版；本机 AVG 曾对新文件启动自动分析，未绕过或修改安全设置。构建成功或安装器退出码不能证明无恶意软件，需保留具体检测结果的边界。
