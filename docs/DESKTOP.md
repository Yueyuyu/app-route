# Windows 桌面版

当前为 0.2 集成测试版。本机可构建、安装并运行；未发布签名安装器或自动更新。

## 构建与安装

使用 Windows 和官方 Node.js 24（Node 安装目录需含 LICENSE）：

```powershell
npm ci
npm run desktop:build
npm run desktop:install
```

输出 `release/AppRoute-win32-x64/AppRoute.exe`，完整目录必须一起保留。安装脚本复制到 `%LOCALAPPDATA%\Programs\AppRoute`，桌面与开始菜单入口直接启动该 EXE。旧同名快捷方式备份到项目忽略目录。更新前从托盘正常退出，不强行结束其他程序。

桌面包包含自身界面、固定扫描脚本、后台、恢复代码和 Node 运行时，不依赖项目、npm、浏览器或 4318 端口。Chromium/Electron、Node 与依赖许可随包保留。安装不启用系统代理、TUN 或开机自启。

## 窗口与托盘

关闭窗口收至托盘，双击托盘或桌面入口重新打开同一实例。托盘可检查新应用、恢复网络、打开独立恢复目录、退出。按 Alt 可打开桌面菜单；Ctrl+Q 正常退出。退出保留已确认分流；未结束事务有独立恢复保护。

恢复网络会停用全部 AppRoute 专属分流，保留 Clash Party 原规则和收藏。桌面程序无法打开时，可使用原来的 AppRoute - Restore Network 独立快捷方式。

## 应用如何出现

- 我的应用：已收藏或实际设置了专属分流的条目。
- 正在运行：已知应用与运行进程按完整路径关联，已识别辅助进程归入主应用。权限不足的进程可能不可见。
- 全部应用：开始菜单、安装登记、可读取商店清单和运行中的可见窗口扫描结果。
- 自动检查：启动和回到窗口时检查，间隔至少 60 秒；窗口可见时每 5 分钟补查。运行状态每 15 秒刷新。
- 立即加入：点击重新扫描，或添加应用 → 从电脑选择程序文件。便携程序没有安装登记时，先运行一次或手动添加。

扫描不是安装事件的实时监听；刚安装的软件不保证同一秒出现。新发现的软件保持按原规则，收藏只改变展示。普通安装条目随扫描更新，手动添加和已发现的便携条目保留。系统工具默认折叠，收藏或已设置分流的工具仍展开。

## 数据与迁移

分流继续读取原 `%LOCALAPPDATA%\AppRoute\state.json`，图标和恢复目录也复用。收藏及资料为 inventory.json，桌面窗口缓存为 desktop 子目录。开发预览的浏览器资料不自动读取；桌面重新扫描、恢复已管理应用，旧浏览器缓存保留。资料文件损坏时不覆盖原文件，不重放缓存里的联网选项。

当前不统计常用程度，不采集窗口标题、使用时长或访问内容。
