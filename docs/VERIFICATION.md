- 自动检查：44 项测试、TypeScript、恢复程序打包和 Vite 构建通过。新增覆盖旧示例迁移、路径隔离、共享目录/目录外进程排除、辅助进程遗漏提示、旧连接排除、规则与出口同时匹配、自动网络检查失败恢复、模拟客户端重新生成及目标消失。

- 自动检查：22 项测试、TypeScript、独立恢复包构建、Vite 生产构建通过。
- 真实进程测试：临时测试进程选择直连后，观察到 DIRECT 新连接；改为指定代理后，观察到对应代理链且没有 DIRECT。仅测试程序被添加规则，没有改变日常应用的分流。
- 代理组检查：应用与恢复前后，所有代理组当前选择一致。
- 恢复检查：恢复后原有 9,193 条运行规则逐条一致；主配置、订阅登记、内核设置、原有覆写及生成配置文件哈希未变。覆写登记仅增加 AppRoute 独立项。
- 独立守护：发起操作的进程退出后完成 120 秒回退；再次关闭 AppRoute HTTP 服务，在整个试运行期间保持关闭，到期仍恢复，状态清空且原规则逐条一致。
- 独立工具：使用复制的 Node 和打包程序，从系统临时目录执行恢复，未依赖项目工作目录或 NODE_PATH；恢复、自检均成功，桌面快捷方式已生成。未人为切断整机外网；恢复流程只使用本机文件及命名管道，联网自检在撤销之后执行。
- 页面：手动添加测试程序、选择直连、应用预览、试运行、保留、全部恢复和网络自检均已验证。最终移除临时草稿、清空测试规则，原示例列表保留。真实路径截图仅存于本机，不提交公开仓库。
- 自动测试覆盖：跨站/伪造会话/超大请求、示例与受保护进程拒绝、重复进程、所有权冲突、外部规则漂移、守护启动失败、重载失败、过期确认、旧守护幂等、按规则仅移除所选应用、内核离线时停用持久化规则、模拟订阅更新/目标消失/重新生成。

### 尚未完成的验收

- Clash Party 会缓存首次登记的覆写列表，需正常退出并重新打开一次；当前本机未进行真实客户端重启、真实订阅刷新或订阅切换。窗口控制工具无法还原其最小化窗口，本轮没有强制终止客户端。界面明确区分运行加载和持久化观测，模拟重新生成测试不能替代此项。
- 页面补充测试时，再次启动临时联网进程被自动审批拦截，未执行该补充步骤；前面的真实进程直连/代理证据来自已成功完成的测试。
- 系统重启/休眠、守护本身被结束、全部事务崩溃点、不同权限/TUN/UDP、其他客户端与版本仍待验证。
- 尚无 Electron 安装包或稳定版发布；构建仍有主 JS 约 1.07 MB（gzip 约 342 KB）的体积提示。
