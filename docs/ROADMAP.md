- [x] 独立全局覆写与目标消失保护，隔离测试验证重新生成；首次登记缓存需客户端重新读取。
- [x] 完成规则校验、变更预览、备份、冲突检查、应用和恢复。

- [x] 精确路径与运行中父子进程识别、独立安装目录组件预识别；页面开启时补充新辅助进程。

验收：一个真实应用完成三种模式的切换和恢复，既有规则得到保留。没有该验证，不把版本标记为可用分流版。

## macOS 实验性预览

已实现应用包扫描、包内辅助进程、当前用户 Unix socket 接入和独立离线恢复；增加 Apple Silicon / Intel 原生 CI 构建与启动验收。尚无 Mac 用户实机分流与恢复证据，不能宣称稳定支持。范围见 [MACOS.md](MACOS.md)。
