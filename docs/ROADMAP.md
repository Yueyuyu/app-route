# 功能规划

状态以可验证结果为准；创建目录或类型定义不算完成对应集成。

## M0：正式项目与开发预览

- [x] AppRoute 命名、独立仓库、架构文档和 AGENTS.md。
- [x] 迁入 Ant Design 页面、示例数据、搜索、筛选、批量修改和应用编辑。
- [x] Windows 只读扫描，与界面和 Vite 桥接分离。
- [x] 草稿本地保存与 JSON 导出，明确标记尚未应用。
- [x] 客户端无关的数据类型，以及内核/配置所有者/接管组件的接口契约。
- [x] 输入约束和扫描接口边界测试；Windows CI 配置。
- [x] MIT、自有/第三方资源说明、贡献说明和问题模板。

## M1：先验证真实接入闭环

- [x] 探测 Clash Party / Mihomo 实际运行方式、控制端点、模式和权限。
- [x] 识别代理组及实际出口，区分入口连通和远端代理。
- [x] 独立全局覆写与目标消失保护，隔离测试验证重新生成；首次登记缓存需客户端重新读取。
- [x] 完成规则校验、变更预览、备份、冲突检查、应用和恢复。
- [ ] 验证客户端重启、订阅刷新、配置切换后行为。
- [x] 观察同一个真实应用的新连接，区分草稿/应用/观测状态。

- [x] 120 秒独立守护、离线运行时、桌面恢复入口、网络自检。
- [ ] 系统重启/休眠、守护异常、权限变化、事务崩溃点覆盖。

验收：一个真实应用完成三种模式的切换和恢复，既有规则得到保留。没有该验证，不把版本标记为可用分流版。

## M2：首版桌面应用

- [x] 本机图标缓存、50 个公共图标、分类默认图标与来源许可目录。
- [x] 设置 → 图标管理，搜索筛选、重新检查、用户替换、公共图标选择、恢复自动及草稿图标迁移。
- [x] 快捷方式/资源 DLL/可读取商店应用图标提取，透明白色商店图形的对比度处理。
- [ ] Electron 主进程与受限 preload IPC，迁移现有扫描功能。
- [ ] 用户数据目录、草稿迁移、设置导入导出、备份管理。
- [ ] 完整的批量应用、失败重试与恢复界面。
- [ ] 运行中进程选择、路径匹配、重复程序和子进程处理。
- [ ] 托盘、显式开机启动选项、仅停用本工具规则。
- [ ] 脱敏诊断与安装包验证，发布适用版本与限制说明。

## M3：扩大兼容

- [ ] 选择并验证第二个 Mihomo 客户端；复用运行控制，增加配置适配。
- [ ] 用户指定的独立 Mihomo 后端。
- [ ] sing-box 适配可行性验证。
- [ ] 通用 HTTP/SOCKS5 端口路线：选择接管组件，验证协议、权限、回环、并存和分发许可。
