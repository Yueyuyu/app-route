## 2026-11-11 桌面验收

解除锁屏后，已安装并打开原生桌面版；以下是桌面实测，未通过浏览器代替：

- 主页面：常用窗口与约 960 × 640 最小窗口可读，窄窗口状态移到应用名下，筛选与代理摘要自动换行。
- 我的应用：问号说明、收藏/取消收藏、只看收藏；清除搜索回到原视图。收藏测试已撤回，未改变网络。
- 搜索：从我的应用找到未收藏软件；中文带空格、英文大写、系统工具进程名；空结果、清除筛选。
- 表格：勾选、取消与更多菜单；没有为 UI 验收改变日常应用的联网选项。
- 应用资料：只读详情、进程折叠、编辑与取消；添加表单空值校验与取消。
- 顶部和侧栏：实际接口连接显示绿色；连接详情、自检、恢复确认与取消。独立恢复入口补齐后，五项自检通过。
- 四页：导航、应用管理、分流规则、图标管理及帮助页布局已检查，最小窗口无横向内容遮挡。
- 图标页：来源筛选显示对应条目；公共图标预选前确认按钮禁用，选中后启用；搜索空结果、取消、上传文件选择取消均通过。
- 帮助页：三种方式卡片与 FAQ 折叠布局清晰，状态颜色说明展开已检查。
- 代理策略：三种模式、候选搜索/勾选、按钮排序、拖动排序、高级参数、空搜索和取消重开已检查；未向日常内核提交测试草稿。

## 检查中修复的问题

- 已连接但未选择代理组时显示“尚未选择代理组”，不误写为未连接。
- 管理记录为空而内核仍加载自有规则时，显示待核对并停用分流提交与记录导出；磁盘旧标记不单独作为运行证据。
- 用户确认后，从带所有权标记的既有覆写静态数据恢复管理记录。逐项核对主程序身份、规则内容/顺序、内核规则和配置；只补本机记录，未重载或改写代理配置。
- 原生 HTML 拖动在桌面复测中未排序；改为指针捕获，拖动与上下按钮均复测成功。
- 主程序和辅助入口可能对应同一分流记录；显示时合并，保留主程序资料，避免重复行与重复计数。
