AppRoute 首个可下载安装的预览版，为应用选择「按 Clash 规则」「直接联网」或「跟随代理组」，配合已有 Clash Party / Mihomo 使用。

### 下载

- Windows x64：`AppRoute-0.2.0-preview.1-setup-x64.exe`
- Mac Apple Silicon（M 系列）：文件名含 `mac-arm64` 的 DMG / ZIP
- Mac Intel：文件名含 `mac-x64` 的 DMG / ZIP
- 每个安装包附带 SHA-256 校验文件。

### 本版内容

真实应用扫描、辅助进程识别、点击自动分流、代理组跟随、故障备用与延迟优先策略、独立离线恢复、托盘、应用筛选、图标管理，以及中英日法四语界面。自检显示时间与过期状态；规则就绪与实际新连接验证分开；关于窗口提供版本与构建信息。

### 已验证与限制

- 三个平台在各自原生 CI 上执行测试、四语桌面检查、真实独立 Mihomo 与守护进程故障测试，并启动最终打包应用检查。Windows 另检查干净环境的安装、覆盖升级、卸载及数据保留。
- Windows 用户实机已验证正常重启及两份真实订阅往返切换，保留原有规则和组选择。
- 2026-11-12 补充：最终 Windows 安装版的桌面交互与带时间自检通过。远程订阅服务返回 HTTP 403，刷新失败后原有分流及配置保持不变；成功刷新后的再生成仍待验收。此为验收记录更新，下载文件未变。
- **仍为预览版，不能按稳定版承诺。** 远程订阅刷新、整机睡眠、断电及完整权限/网络矩阵尚未验收。
- **Mac 为实验性版本。** 尚无用户 Mac 上真实 Clash Party 应用分流与恢复证据；原生 CI 通过不代表真实客户端验收完成。当前 CI 使用 macOS 15。
- Windows 安装器未签名；Mac 仅做 ad-hoc 签名，未取得 Apple Developer ID 签名和公证。系统可能提示无法验证发布者或阻止打开。没有自动更新。
- AppRoute 不提供代理节点；只管理自己的规则与策略，不重置系统代理或网卡。未进入 Mihomo 的流量不保证被接管，旧连接不会强制切换。

English: Preview release, not stable. macOS Apple Silicon and Intel builds are experimental; native CI is verified, real Mac/Clash Party routing is not. No publisher signing, Apple notarization or automatic updates.

日本語：安定版ではありません。macOS は実験版です。原生 CI の検証と、実機での Clash Party の振り分け検証は別です。署名・Apple 公証・自動更新は未提供です。

Français : Préversion, non stable. Les versions macOS sont expérimentales ; les tests CI natifs ne remplacent pas la validation réelle avec Clash Party sur Mac. Pas de signature d’éditeur, de notarisation Apple ni de mise à jour automatique.
