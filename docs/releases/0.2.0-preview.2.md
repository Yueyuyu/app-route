## 升级方式

1. 从托盘菜单完全退出 AppRoute，关闭窗口只会隐藏。
2. Windows 运行新 EXE；Mac 替换“应用程序”内的 AppRoute.app。
3. 重开后检查“关于”中的版本、原应用设置和当前连接，再执行网络自检。

正常升级保留本机设置及恢复数据，不要删除用户数据目录。没有自动更新；不承诺直接降级的数据兼容性。仅退出或卸载不会撤销已经持久化的分流；不再使用前先执行[恢复网络](https://yueyuyu.github.io/app-route/maintenance.html#恢复网络)并检查结果。

## 已知限制

- Windows 未签名；Mac 仅 ad-hoc 签名，无 Apple Developer ID 公证。遇到拦截时核对官方来源、文件哈希和准确提示；明确威胁检测需另行调查，不建议关闭防护。
- Mac 已通过双架构 CI 构建和打包启动检查，**尚无 Mac 实机 Clash Party 分流与恢复证据**。
- 远程订阅服务曾返回 HTTP 403，失败保留检查通过，成功刷新后的再生成仍待验证。
- 未确认事务跨睡眠、断电、完整权限和网络兼容矩阵仍待完成。正常睡眠检查不覆盖全部电源状态。
- 部分本机启动检查出现等待窗口超时，后续启动成功；尚无足够证据确定原因或归因杀毒软件。若窗口不出现，请保留版本和错误，按[故障指南](https://yueyuyu.github.io/app-route/faq.html)反馈。

## 本次修复与验证

Mihomo v1.19.32 的备用组在固定节点失效后可能回到自动选择，但仍保留旧选择缓存。重载可能读回该缓存。现在重载前同步已经处于自动状态的组，并检查选择及成员变化；保留手动选择和仍有效的固定节点。应用、回退和恢复共用此保护。

- Windows 101 项自动测试通过，另 2 项仅在 Mac 原生运行；Mac 两种架构各 103 项通过。三平台包含打包启动及独立真实内核的自动/手选/固定组选择检查。
- 55 项四语桌面检查使用隔离演示后台；不作为实际网络写入证据。
- Windows 正常睡眠唤醒、规则及组选择保留和 5/5 自检来自 preview.1 稳定状态验收，不代表未确认事务跨睡眠已验收。
- 二进制来源：[ba77f05733e2](https://github.com/Yueyuyu/app-route/commit/ba77f05733e249abd81bb082ea551d46e941af86)；[发布构建记录](https://github.com/Yueyuyu/app-route/actions/runs/43143147834)。本次文档与汇总附件完善不改变原安装包。
