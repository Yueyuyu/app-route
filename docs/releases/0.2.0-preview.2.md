AppRoute 应用分流预览更新：修复重载配置时自动代理组可能重新固定到旧节点的问题。

### 本次修复

Mihomo v1.19.32 的备用组在固定节点失效后可能回到自动选择，但仍保留旧选择缓存。AppRoute 重载配置时可能读回这个缓存，导致分流操作回退。现在重载前同步已经处于自动状态的组，并检查选择和成员是否发生变化；保留手动选择以及仍有效的固定节点。应用、回退和恢复共用这层保护。

### 验证范围

- Windows 真实正常睡眠与唤醒已核对：原有分流、规则顺序和组选择保持不变，唤醒后自检 5/5；旧检查结果显示需要重新检查。此结果来自 preview.1 的稳定状态，不代表休眠中尚未确认事务、断电或所有电源状态已验收。
- 缓存问题使用独立真实 Mihomo 和回环探测复现；修复后自动/手选/固定选择检查通过，没有改写日常配置。三平台发布流程要求该检查和打包应用检查都通过。
- 远程订阅服务返回 HTTP 403，成功刷新后的再生成仍待验证。Mac 真实 Clash Party 分流与恢复尚无实机证据。

### 下载与限制

- Windows x64：`AppRoute-0.2.0-preview.2-setup-x64.exe`。
- Mac Apple Silicon / Intel：分别选择 `mac-arm64` / `mac-x64` 的 DMG 或 ZIP；Mac 仍为实验性版本。
- 每个安装包附 SHA-256。Windows 未签名，Mac 仅 ad-hoc 签名、无 Apple Developer ID 公证；没有自动更新。旧版资产保留，不覆盖原文件。
- **仍为预览版，非稳定版。** 未完成的权限、断电、未确认事务跨睡眠及完整网络兼容矩阵见仓库验收记录。
