# 侧栏底部工具区

2026-11-18：用户要求重新组织连接状态、实际版本、更新和 GitHub 入口。复用现有浅色侧栏与 Ant Design，不改已确认的品牌标志、桌面图标或联网选项。

## 信息层级

- 连接行：Clash Party 名称与状态上下排列，使用状态点和文字共同表达连接情况；向上的箭头对应上方展开的连接概况。绿色仅表示控制接口连接，不代表所有节点和应用流量已经验证。
- 工具行：左侧显示构建版本，点击查看关于；右侧是 GitHub 图标和更多菜单。反馈问题、在线文档与更新日志放在菜单里，不再平铺按钮。
- 更新提示：查询到更高且附件完整的版本时出现，显示新版本；下载期间显示进度，完成显示“可安装更新”，失败保留重试入口。查询失败、暂无稳定版、附件缺失不得显示为“已是最新”。

## 视觉与交互

2026-11-19 调整：底部融入侧栏底色，仅用顶部细分隔线区分导航和工具区，移除包裹卡片和插头图标底块。连接名称 14px、状态 12px，增加可读性；连接正常为绿色，连接异常为红色，正在连接为蓝色，未连接为中性灰。整行可点击，悬停、键盘焦点或展开时才显示轻底色，箭头在展开后朝下。版本、GitHub 和更多菜单保持次要层级，不再添加第二条分隔线。

图标按钮保留明确名称、悬停提示、按下反馈和键盘焦点。普通侧栏与窄屏导航使用相同入口，四种语言可换行，版本号不能被省略成“预览版”。

连接概况、关于和版本更新分开呈现，Esc 关闭后回到相应入口，关闭弹窗不会取消下载。实际安装准备阶段暂停关闭与写入，避免用户看不到正在进行的升级。自动检查、下载状态由共享状态管理，后台检查失败不打断用户；下载和安装分别需要明确点击，升级契约见 [更新流程](../UPDATES.md)。

实现入口：`ConnectionStatus.tsx`、`AboutApp.tsx`、`useReleaseUpdates.tsx`、`styles.css`。公开演示继续使用隔离虚构应用，不复制本机真实应用清单。
