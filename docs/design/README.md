# 界面约定

使用 Ant Design，正式品牌为 AppRoute 应用分流。导航采用应用管理、分流规则、图标管理、使用帮助四个平级入口。已保存的实际规则不再称为草稿。

## 视觉

- 浅灰蓝画布、白色卡片、浅灰侧栏，主色 `#3265ed`，文本 `#202938`；直接联网选项使用绿色。
- 桌面侧栏 216px，小窗口 190px；顶部栏 52px，内容左右留白 28px，小窗口 20px。
- 使用 Ant Design Table、Drawer、Segmented、Form 等真实组件，避免重复自造控件。
- 小屏使用抽屉导航，保留三种联网方式的完整名称。

## 文案与状态

首个接入对象是 Clash Party，因此界面解释“按 Clash 规则”“直接联网”“跟随代理组”的具体含义。新增其他执行端时，文案必须跟随当前后端，且说明规则来自哪里、代理出口是什么。

显著标注开发预览、示例数据和未连接状态。不得把 localStorage 保存成功表达成网络已生效。

集成测试版区分规则加载、连接验证和持久化观测。正常摘要只显示代理组与当前节点；恢复网络保留常驻按钮，自检与离线恢复路径放入“连接详情”。preview.jpg 为 0.1 示例界面历史截图。

## 信息层次与交互

- 应用行只展示图标、名称、主进程摘要、简短状态和联网方式；窄屏把状态移到名称下方，不堆叠详细说明。
- 状态可点击问号查看解释；应用名称打开只读详情，再从详情进入资料编辑。进程列表、程序路径、已绑定组和实际连接证据在详情中查看。
- 蓝色“规则已加载”表示内核已有规则；绿色“已验证新连接”表示观察到符合设置的连接；黄色只用于需检查事项，红色表示异常。不能将蓝色自动提升为已验证。
- 左下角的绿点来自控制接口连接状态，接口读取失败立即取消绿色；启动了客户端不等于控制接口可连接，连接成功也不等于节点健康。
- “我的应用”由收藏或已设专属分流组成，不推断使用频率。星标只影响收藏，问号说明收录原因。
- 搜索覆盖全部应用，不受当前标签或系统工具折叠限制；名称、进程、路径均可匹配。显式分类/联网方式/收藏筛选继续生效，并显示清除入口。
- 问号使用可点击、可键盘访问的 Popover；帮助页用三种方式卡片与问题折叠层承载完整说明。
- 选择公共图标先预选，再点击“使用此图标”；代理策略勾选/排序只改当前草稿，点击应用才进入原有事务。恢复确认说明影响范围，不使用泛泛的“确定”。
- 普通说明不常驻大面积 Alert。连接失败、规则不一致、非规则模式、失效节点等可操作问题继续直接显示。
- 管理记录缺失但历史自有规则仍在内核运行时，显示“状态待核对”，不能用默认选项或空列表暗示没有分流；暂缓提交和导出，核对记录后再恢复操作。
- 同一管理记录的主程序与辅助入口合并为一行，优先使用主程序资料，避免“我的应用”重复计数。

实现入口：`HelpTip.tsx` 为点击解释，`ApplicationStatus.tsx` 统一状态，`ApplicationDetails.tsx` 承载只读详情；搜索与视图规则集中在 `core/applicationViews.ts`。本轮桌面视觉验收状态见 `docs/VERIFICATION.md`。

## 资源

艺术字定稿、哈希及跨项目风格来源见 [字标规范](wordmark.md)；本项目保留品牌使用约束，通用正反例与生成描述在 UI Design Lab 视觉风格库维护。

应用标识按场景使用两种已确认外观：应用内采用透明箭头，与艺术字组合，不添加包边或阴影；桌面快捷方式、浏览器标签页和独立展示采用 02「适中提亮」深灰蓝圆角底。两者共用同一张青蓝手写分流箭头：左短右长，分别向左上、右上展开。原图、精确参数、PNG、Windows ICO 及再导出方法见 [应用图标](app-icon.md)。应用内统一引用 `app-route-inline.svg`，不再共用桌面 PNG。

侧栏与手机导航的 AppRoute 名称使用已确认的圆润连笔艺术字：在手写版本上小幅收细笔画，保留青蓝渐变。`public/brand/app-route-wordmark.png` 保存定稿原图，`src/renderer/components/Brand.tsx` 统一组合图标、字标与中文副标题。SVG 仅作为原图显示视窗收起四周留白，不重绘笔画；浅色背景以 CSS 正片叠底融合白底，后续深色主题须另行验证。桌面字标宽 126 像素，收窄侧栏时为 116 像素，手机导航为 146 像素；读屏名称仍为 AppRoute。

公共图标从带许可记录的目录生成；扫描得到的真实图标独立保存在本机缓存。原型中的本机截图和从已安装 EXE 提取的静态素材不进入公开仓库。来源、匹配顺序与验收标准见 [图标库与缓存](application-icons.md)。
