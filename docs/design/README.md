# 界面约定

沿用已有 Ant Design 原型，正式品牌为 AppRoute 应用分流。当前版本保留应用管理、规则草稿、使用说明三页。

## 视觉

- 白色内容区、浅灰侧栏，主色 `#3265ed`，文本 `#202938`；直接联网使用绿色语义。
- 桌面侧栏约 274px，顶部栏 68px，内容左右留白 28px。
- 使用 Ant Design Table、Drawer、Segmented、Form 等真实组件，避免重复自造控件。
- 小屏使用抽屉导航，保留三种联网方式的完整名称。

## 文案与状态

首个接入对象是 Clash Party，因此界面解释“按 Clash 规则”“直接联网”“强制走代理”的具体含义。新增其他执行端时，文案必须跟随当前后端，且说明规则来自哪里、代理出口是什么。

显著标注开发预览、示例数据和未连接状态。不得把 localStorage 保存成功表达成网络已生效。

集成测试版将“已加载规则”“已观察到符合设置的新连接”“已观察到客户端生成持久化规则”分别呈现。网络自检和恢复放在应用页面上方；试运行确认倒计时明确显示，独立离线恢复路径常驻检查区域。preview.jpg 为 0.1 示例界面历史截图。

## 资源

应用标识采用已确认的浅蓝底分流图标：左侧白色箭头较低，右侧薄荷绿箭头较高。原图、各尺寸 PNG、Windows ICO 及再导出方法见 [应用图标](app-icon.md)。界面和网页图标统一使用该定稿；保留不对称造型，不对齐两侧箭头。

公开示例图标从带许可记录的图标集生成；扫描得到的真实图标仅保存在本机草稿。原型中的本机截图和从已安装 EXE 提取的静态素材没有迁入公开仓库。
