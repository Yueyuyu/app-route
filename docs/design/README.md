# 界面约定

沿用已有 Ant Design 原型，正式品牌为 AppRoute 应用分流。包含应用管理、规则草稿、使用说明，以及设置下的图标管理。

## 视觉

- 白色内容区、浅灰侧栏，主色 `#3265ed`，文本 `#202938`；直接联网使用绿色语义。
- 桌面侧栏约 274px，顶部栏 68px，内容左右留白 28px。
- 使用 Ant Design Table、Drawer、Segmented、Form 等真实组件，避免重复自造控件。
- 小屏使用抽屉导航，保留三种联网方式的完整名称。

## 文案与状态

首个接入对象是 Clash Party，因此界面解释“按 Clash 规则”“直接联网”“强制走代理”的具体含义。新增其他执行端时，文案必须跟随当前后端，且说明规则来自哪里、代理出口是什么。

显著标注开发预览、示例数据和未连接状态。不得把 localStorage 保存成功表达成网络已生效。

集成测试版将“已加载规则”“已观察到符合设置的新连接”“已观察到客户端生成持久化规则”分别呈现。网络自检和恢复放在应用页面上方；试运行确认倒计时明确显示，独立离线恢复路径常驻检查区域。preview.jpg 为 0.1 示例界面历史截图。

## 资源

艺术字定稿、哈希及跨项目风格来源见 [字标规范](wordmark.md)；本项目保留品牌使用约束，通用正反例与生成描述在 UI Design Lab 视觉风格库维护。

应用标识按场景使用两种已确认外观：应用内采用 03 随形轮廓，与艺术字组合；桌面快捷方式、浏览器标签页和独立展示采用 02「适中提亮」深灰蓝圆角底。两者共用同一张青蓝手写分流箭头：左短右长，分别向左上、右上展开。原图、精确参数、PNG、Windows ICO 及再导出方法见 [应用图标](app-icon.md)。应用内统一引用 `app-route-inline.svg`，不再共用桌面 PNG。

侧栏与手机导航的 AppRoute 名称使用已确认的圆润连笔艺术字：在手写版本上小幅收细笔画，保留青蓝渐变。`public/brand/app-route-wordmark.png` 保存定稿原图，`src/renderer/components/Brand.tsx` 统一组合图标、字标与中文副标题。SVG 仅作为原图显示视窗收起四周留白，不重绘笔画；浅色背景以 CSS 正片叠底融合白底，后续深色主题须另行验证。桌面字标宽 156 像素，收窄侧栏时为 122 / 116 像素，手机导航为 146 像素；读屏名称仍为 AppRoute。

公共图标从带许可记录的目录生成；扫描得到的真实图标独立保存在本机缓存。原型中的本机截图和从已安装 EXE 提取的静态素材不进入公开仓库。来源、匹配顺序与验收标准见 [图标库与缓存](application-icons.md)。
