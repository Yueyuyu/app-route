# 自动界面验收预览

运行 `npm run check:ui-preview`，完成真实 Electron 界面的四语、设置操作及首屏故障隔离检查后，打开 `output/ui-review/index.html`。它包含按语言分组的页面和弹窗截图、实际内容尺寸、操作断言、源码 SHA 与内容摘要。点击截图可查看原图。

日常 CI 在涉及 UI 的程序检查中自动生成报告；纯文档不触发。发布前完整验收也生成报告。Actions 摘要说明入口，下载 `checks-windows-latest`、`checks-macos-15` 或完整验收的 `verification-*` 产物，解压后打开其中的 `ui-review/index.html`。无需部署外网预览、AI 密钥或写权限，也不会自动评论 PR 或公开发布版本。

## 防止旧截图冒充新结果

- 每个套件开始先撤下旧汇总、清理自己的生成目录并写入运行中标记；全部操作、退出与边界检查通过后才写成成功。
- 每张截图记录 SHA-256、语言与 PNG 的真实宽高；报告汇总前再次校验截图内容。
- 记录包含已跟踪及未跟踪源码的内容摘要；执行中源码变化、跨版本混用、缺少某套件或上次失败，均拒绝生成成功报告。未提交的本地快照明确标注，不能只引用 HEAD 当成已提交内容。
- 页面只包含演示数据。产物保留 7 天，失效后重新执行；不长期累计真实扫描结果或代理配置。

## 人工复核

自动断言覆盖布局溢出、资源加载和交互，并不判断“好不好看”。复核品牌比例、行距、弹窗层次、长文案与窄屏效果；发生 UI 变更时将本次报告与上一次相应版本报告并排查看。当前不做像素级视觉差异判定，避免动态日期、字体渲染差异被误报为产品问题。

这些截图的尺寸是受控内容视口，不代表 Windows/macOS 原生窗口缩放；数据和代理均为夹具，不代表 Mac 实机联网、真实休眠或安装验收。上述边界必须随提交证据说明。
